# GranApp - PWA para Motoristas

GranApp ayuda a conductores a maximizar sus ganancias.

## 🌍 Características
- Calculadora de Ganancias
- GranScore
- Cámara Secreta

## 📱 Plataformas
- 🇧🇷 Brasil: Uber, 99
- 🇪🇸 España: Uber, Cabify
- 🇺🇸 USA: Uber, Lyft
